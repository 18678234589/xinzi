# 上传表格在线编辑

在「上传文件」中打开表格，或从导入核对页面点击「编辑全部字段」。

1. 双击单元格编辑，或点选后使用上方输入框；订单号、日期、参与人、备注及其他原表字段均可修改。支持从 Excel 粘贴多格内容。
2. 修改自动保存，也可点击「保存修改」。使用顶部滚动条、左右按钮或手机横向滑动查看其他列。
3. 点击「核对并提交到系统」，等待全部修改保存后进入导入核对页面，再确认导入。无需下载、重新上传附件。

原始附件保持不变。编辑值保存在 `project_import_edits`，导入解析读取保存后的版本；自定义原表字段也会保留在编辑记录中。

同号已存在的订单仍按现有导入合并规则处理，不自动覆盖已有分成或已结算数据。订单号改变会按修改后的号码核对。「更正已导入订单资料」保留原有售价、店铺、昵称和续费资料更正流程。

保存按最多 500 格分批进行；保存失败时保留本地队列并阻止提交。核对后再修改表格，需要重新核对，不能提交旧预览。补充列布局随首次保存固定，财务代导不会按不同岗位错配列。

## 验证

- PHP 7.4：`tests/sheet_editor_smoke.php`，仅允许本地隔离数据库。
- `tests/website_split_import_smoke.php` 包含在线编辑后的实际核对、建单和旧预览拒绝场景。
- `tests/sheet_editor_browser.cjs` 使用 Playwright 和本地模拟接口，验证桌面、手机触屏横向滚动、1500 格分批保存、失败重试及提交顺序，不连接生产数据库。
- 部署后通过公网 HTTPS 只读检查实际表格页面，验证全部列可编辑、滚动正常且无脚本错误。

部署仍使用 `tools/deploy_hezuoshang.py` 的 fetch 基线、dry-run、正式 push 和 smoke。FPM 重载通过 `docker kill --signal=USR2 hezuoshang-php`，不依赖容器内安装 `kill` 程序。

## 我的在线表格（直接在网页里录单）

合作人员在「我的表格」页顶部、或工作台的「我的在线表格」卡片里，选**月份 + 业务**后点“打开在线表格”：每个月每个业务一张在线表格，表头就是该业务的订单模板。

- 像 Excel 一样填：点下拉格直接展开选项；从电脑上的 Excel 复制一片内容，点中要贴的第一格 Ctrl+V 即可，超出末行时自动新增行；也可以点“新增行（+1 / +10 / +50）”。一张表最多 3000 行。
- 改动自动保存（`project_import_edits`，新增行的总数存在 `row_no=0,col_idx=1`）；停手约 8 秒后自动同步到系统，也可点“立即同步到系统”。
- 同步走和“上传表格”完全相同的核对 / 导入代码（`includes/ProjectOnlineSheets.php` 里 `pols_sync` 用 `project/import.php` 的 repreview + commit），只处理内容有改动的行；每行结果写在最右边的“系统状态”列（✓ 已同步 / … 还没填完整 / ✗ 需处理：原因），不弹“待补全”、不发站内信。
- 订单号改了：旧订单是还没审核的草稿就自动撤销（进回收站，30 天内可还原），否则保留并在状态里提醒；行被清空：订单保留，提醒去订单页删除。
- 在线表格不能“删除原件”；财务查看别人的在线表格按普通表格处理（不会替对方同步）。
- 验证：`tests/online_sheet_smoke.php`（后端，隔离库）、`tests/online_sheet_browser.cjs`（浏览器，模拟接口）、`tests/online_sheet_e2e.cjs`（真实页面 + 真实接口 + 隔离库，需本地服务，见文件头）。
