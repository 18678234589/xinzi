# 商务中国域名管理

入口：页头「自媒体工作台」右侧「域名管理」，页面 `project/domains.php`。

## DNSPod / Cloudflare 解析管理

### A 记录改为 CNAME 的保存修复（2026-10-13）

商务中国按「类型、主机、旧值」定位记录，不能用原修改接口直接变更类型。相同主机改为/改出 CNAME 时，原记录与新记录互斥，需要先删除原记录再添加新记录；添加失败会尝试恢复原记录，恢复失败明确列出需要补回的类型、主机和值。存在其它同名冲突记录、旧记录已被别人更改、目标已存在或 CNAME 值无效时，在写操作前拒绝，不擅自删除其它记录。非冲突的主机变更仍先添加后删除。

保存成功/失败提示显示在解析记录区并滚动到可见位置，编辑表单关闭后成功提示仍保留；列表刷新失败会保留保存结果并单独提示刷新失败，避免重复提交。DNSPod/Cloudflare 页面保存后的成功/错误通知也会自动进入可见区域。根据注册商 NS 提醒实际解析商，指向外部 DNS 时明确商务中国记录不改变外部解析，并提供本站 DNS 管理入口。

回归：`php tests/bizcn_record_replace.php`（18 项，模拟互斥、失败恢复、恢复失败、其它同名记录及并发变更）；`node tests/bizcn_record_save_ui.js`（16 项，模拟实际编辑与保存、可见提示、刷新失败和外部解析提醒）。未用客户域名做写操作测试。

域名页顶部「在本站管理解析」以及域名详情「在本站管理 DNSPod / Cloudflare 解析」进入 `project/dns.php`。网站技术、网站客服、网站售后部门均可使用；访问和写操作共用域名管理权限，不要求平台信息白名单。首次登录仍需按账号页面完成改密和手机号绑定。

DNSPod 和 Cloudflare 均通过已有 API 在本站创建域名、管理解析记录、预览并确认复制，无需登录腾讯云或 Cloudflare。详情页按当前选择的服务商展示接入引导；已接入的域名可直接增删改记录，不用再次修改 NS。商务中国「智能 DNS」预设与我们账号内的 DNSPod API 管理分开：后者使用 API 返回的实际 NS，不能把预设的 `bizcn1/2.dnspod.net` 当作账号实际分配的 NS。

接入 Cloudflare 按页面三步操作：创建区域取得 NS → 预览并确认复制现有记录 → 核对完整后修改注册商 NS。商务中国和 DNSPod 可作为复制来源；已有记录不覆盖，暂不支持的类型明确列出。原解析在其它服务商时，先查看或导出实际生效的记录，再在 Cloudflare 手动添加网站 A/CNAME、邮箱 MX/TXT 等记录，不能把商务中国账户里未生效的旧记录当作当前解析。NS 传播期间保留旧解析。

商务中国账户内域名可输入域名确认后修改 NS；其它注册商需按页面展示的 NS 去其后台修改。页面检测公网 NS，提供复制按钮、记录增删改和操作审计。凭据复用「接口设置」中的加密配置，不进入 Git。

2026-10-12 线上只读复核：网站技术3个、网站客服4个、网站售后8个启用账号均满足权限；抽取各类已完成账号设置的账号，域名页、解析总览、Cloudflare详情均返回HTTP 200并显示引导，无权限商标账号返回403。没有修改真实客户解析。离线假服务商测试53项通过，覆盖创建区域、记录增删改、复制、重复记录和错误处理，并确认没有加载真实凭据或数据库连接。

### 域名注册（2026-10-12）

页面新增「注册域名」，首期一年注册：选择管理员批准的实名模板 → 实时核验可注册性和价格 → 展示域名、实名主体、NS、人民币金额 → 勾选确认及再次确认扣费 → `domainService/addDomainByID`。查询不购买，提交时再核价，价格变化需要重新确认。非管理员不能购买 premium 高价域名。

每日默认上限12个，全平台同一商务中国账户共享，按北京时间自然日。仅管理员可以修改（0暂停、1–1000）；普通主管角色不拥有配置权限，页面自身的域名访问权限不因此扩大。首次启用须管理员选择已通过实名的模板、核对真实主体并配置两个实际 NS；不擅自选用客户的身份模板或示例 NS。

配额决定通过账户设置行锁串行化。报价5分钟有效，绑定发起人、金额、主体、NS 和设置版本；提交由服务端快照取参，不信任前端价格。token 哈希唯一；同一账户+域名活动锁唯一。持久化 `unknown` 再进行一次付费调用，重复提交或超时不会重复注册。

`status=200` 才确认已注册；`1`处理中；`3`明确失败释放额度；其余或传输异常保留额度并等待核对，HTTP/API结果200本身不表示注册成功。未解决的前日申请继续占用今日额度，跨日确认也计入确认日，采用保守限额避免异步订单超额。成功域名写入目录，`import_id=0` 区别于导出快照；刷新显示API新增数量，不伪造导出日期。目录写入异常不触发再次购买。

申请记录限本人查看，管理员可查看全部。已知注册商订单号可只读查询结果；未知订单号可由管理员补关联，必须精确核验域名和注册商订单号。管理员向注册商确认「未注册、未扣款、无处理中订单」后可填写核验依据关闭未知申请；刚提交请求暂不允许人工释放，防止与正在进行的购买同时操作。整个过程留审计记录，不自动产生薪酬成本。

### 新客户实名与模板自助查找（2026-10-13）

业务多为新客户、新实名，不再要求管理员预先逐个批准模板：注册区新增「客户实名主体」查找框，所有有域名管理权限的人员（网站/小程序的客服、技术、售后等，权限规则不变）可按主体名称、模板名称或模板编号在已同步目录中查找（至少2字，最多20条，不提供全量浏览）。选中后报价与提交仍实时核验模板审核状态必须为 `pass`，报价单显示实名主体名称供核对；管理员批准的模板仍保留为常用项。

新客户流程：点「新客户？去商务中国创建实名信息」（动作 `registration_panel`，与域名详情里的官方面板同权限并写审计）→ 在「域名管理 > 添加域名模板」填写主体、上传证件、验证手机邮箱 → 商务中国 2-5 个工作日审核 → 通过后回到注册区点「刷新最新实名并查找」（动作 `registration_find_template`，`refresh=1` 时先同步 `getTemplateList` 第1页；列表按审核通过时间倒序，一页50条覆盖新增）→ 选择并注册。证件图片、证件号、电话、邮箱只在商务中国页面填写，本系统不收集、不留存。审核通过前无法用该实名主体注册域名。

默认 NS 在管理员未设置时使用 `ns7.cnmsn.net` / `ns8.cnmsn.net`（`br_default_ns()`，与现有域名一致），管理员保存配置后以保存值为准。每日上限仍为全平台12个（线上设置行已是12）。顶部导航增加「注册域名」，直达 `project/domains.php#register`。

### 智能识别实名信息并提交模板（2026-10-14）

注册区「新客户：智能识别营业执照 / 身份证」：粘贴客户文字 + 上传证件图片（JPG/PNG，最多4张，身份证正反面自动上下拼成一张）→ 先用规则识别手机、邮箱、身份证号 / 统一社会信用代码（校验位通过才采信，优先于图片 OCR），再由系统设置里的 AI（OpenAI 兼容，需支持图片输入；线上模型实测可读图）补全主体、姓名、省市、地址、邮编和英文 / 拼音字段 → 人工逐项核对（校验不过或缺项的字段高亮）→ 勾选确认后提交商务中国 `domainTemplateService/addTemplate`（`cert_type + file_1/file_1_name/file_1_code` 方式，元素顺序同 WSDL；单位 `templatetype=1/companytype=PU`，个人 `2/PR`）。返回模板编号后可「查询审核进度」（`queryTemplateAuthStatus`），商务中国审核 2–5 个工作日，通过后「刷新最新实名并查找」选用。

- 省份、城市必须是接口文档附录二的写法，数据在 `includes/BizcnRegions.php`（31省345市），页面用下拉选择。
- 证件图缩放压到 ≤900KB 的 JPG（商务中国要求 55K–1024K，过小直接拒绝而不是填充）；浏览器端先缩到最长边2000。
- 隐私：图片、证件号只在内存中处理并转发，不落盘、不入库；审计只记录模板名称、类型、商务中国模板编号，不记证件号、电话、邮箱。**图片会发送给系统设置里配置的 AI 服务商做识别**，AI 失败或未启用时只按文字规则填写能确定的部分。
- 手机、邮箱须是商务中国账户已验证的：管理员可在注册设置里保存「默认手机 / 邮箱」，客户没提供时自动填入并高亮提示。
- 离线测试：`php tests/bizcn_template_ai.php`（53项，AI 与商务中国接口均为替身）。线上用合成营业执照（无真实信息）验证过「读图 → 填字段」，**尚未用真实资料调用过 addTemplate**，首次提交请由业务人员实测并留意商务中国返回的报错（例如未验证的手机 / 邮箱）。

### 一键预检（2026-10-14）

识别框移到注册区最上方，粘贴「域名 + 公司名 + 电话 + 邮箱 + 地址」（可再传执照）后：识别 → 自动 `registration_precheck`（只读）显示三项结果：域名能否注册及一年价格（`checkPremium`，高价域名标明仅管理员可注册）、该公司在商务中国是否已有实名模板（按主体名称精确匹配，先同步最新一页，再逐个 `queryTemplateAuthStatus`：通过 / 审核中 / 无）、下方预填好的实名表单。模板已通过且域名可注册时出现「使用该主体注册」，自动填入域名与主体并生成报价（仍需勾选确认才扣费）；没有模板则核对后「提交实名审核」（confirm 弹窗列出主体、证件号、电话邮箱后直接提交）。审核通过后再粘贴同样的文字（不需要再传图片）即可走注册。域名取文字中第一个 `name.tld`（忽略邮箱和网址），识别不到可在预检区手填并「重新预检」。

邮编按城市默认填入（`includes/BizcnPostcodes.php`，337 个城市市区主邮编，不细到区县；由 AI 生成并抽查无锡、济南、广州、深圳、杭州等一致，邮编不参与实名审核），城市来自省市识别或地址文字；表中无该城市时才用 AI 给的邮编。

### DNS 单选与实名模板搜索

已有域名的 NS 设置和管理员注册默认 NS 均提供三选一：

| 方式 | NS1 | NS2 |
| --- | --- | --- |
| 默认 DNS | ns7.cnmsn.net | ns8.cnmsn.net |
| 智能 DNS | bizcn1.dnspod.net | bizcn2.dnspod.net |
| 自定义 DNS | 自行填写 | 自行填写 |

选择预设只在页面填值，不发起网络写操作；自定义保留可编辑的 NS 输入，旧域名的其他 NS 不被自动改掉。智能 DNS 提醒域名须未在 DNSPod 注册或添加解析，此单选项不会自动核验该限制。正式修改仍需提交并二次确认、实时归属核验和原有审计。

生产只读复核发现 `getTemplateList` 忽略 `templatename/contid` 筛选，单页最多50条；并非参数拼写错误，已对照 WSDL 并分别测试名称、编号及分页。因此在管理员专用 `bizcn_registration_templates` 缓存编号、名称、实名主体三个必要字段，不缓存电话、邮件、地址、证件。搜索在本系统进行，明确展示已同步目录数量；首次或后续更新可点击「同步可搜索模板目录」。模板注册前仍实时核验审核状态。分页同步不批准模板，也不注册域名。

## 权限
