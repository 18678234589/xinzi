# 对外用语对照（内部文档，不部署、不对用户展示）

系统对外把合作人员的服务按“服务关系”表述，用户可见的页面、提示、导出文件不使用劳动管理术语。

| 老词（内部 / 代码里的叫法） | 对外用语 |
| :--- | :--- |
| 考勤表 / 考勤记录 / 考勤 | 服务时长确认单 / 服务时长确认单 / 服务时长确认 |
| 出勤表 / 出勤 | 到岗确认单 / 到岗确认 |
| 缺勤记录 / 缺勤 | 未履约记录 / 未履约 |
| 打卡记录 / 打卡 | 签到确认 |
| 值班表 / 值班 | 排班时段表 / 排班时段 |
| 工时统计表 / 工时 | 服务时长 |
| 请假记录 / 调休记录 / 请假 / 调休 | 服务暂停申请 / 时段调整确认 / 服务暂停 / 时段调整 |
| 加班 / 加班费 | 延时服务 / 超时补贴 |

## 实现方式

- `includes/ProjectTerms.php`：词表 + `pt_filter_html()`。`includes/header.php` 顶部调用 `pt_start()`，之后整页输出里“标签之间的文字”和 title / placeholder / alt / aria-label 等提示属性自动换词；script、style、textarea、HTML 注释、表单 value、链接地址不处理。
- 下载文件、JSON 等非网页输出不经过替换：这类输出、以及脚本里的 alert / confirm 提示语，要在源码里直接写对外用语。
- 数据库字段（`attendances.absent_hours` 等）、规则类型代码（`overtime_pay`）、URL（`/attendance/`）保持不变。
- 上传表头识别新旧叫法都认：满勤 / 应出勤 / 应到岗确认、实际出勤 / 实际到岗确认、请假 / 服务暂停、缺勤 / 未履约。
- 回归：`php tests/project_terms_smoke.php`。
