# 管理账户

成本中心“账户角色”支持技术、客服、管理。管理账户可填写职务，选择“已分配业务”或“全公司所有业务”。账户维护仍由财务执行。

- 已分配业务：可以查看、录入这些业务的同事订单，管理相应的上传表格与部门知识；不自动参与订单分成。
- 全公司所有业务：上述操作覆盖所有业务，并可查看重复订单号说明、审核部门成本更改申请。新业务与新部门也自动纳入范围。
- 管理账户继续使用员工登录入口和首次手机号绑定流程；页面显示管理职务。管理范围撤回或账号停用后立即生效。
- 财务审核、锁月、规则修改和发放权限继续由原财务校验控制。已审核订单的保护规则继续适用。

管理账户身份与分成组分开。既有订单填报代码使用兼容的客服上下文，`account_role` 保存管理身份；`project_account_management` 保存管理范围与职务。主管代录时不自动追加本人为参与人，原表指定的实际客服、技术人员仍是结算对象。

固定薪酬主管可勾选“仅固定薪酬”。即使被表格或表单明确选为参与人，也只保留零分成记录，不领取客服提成、计件补助，不占用实际参与人的组内权重。已审核快照继续冻结。

部署前执行 `php migrations/apply_management_accounts.php`。它扩展账户角色枚举并创建管理范围表，可重复运行；不会调整工资、历史分成或人员部门。

薪酬在规则中心另行配置：固定服务费使用 `base_fee`，全勤奖使用 `attendance_bonus`，每月固定补助使用 `fixed`。固定服务费按现有考勤口径折算；全勤奖需要财务批准，不能把未批准金额当成已核定报酬。

验证：在本地隔离数据库运行 `tests/project_management_accounts_smoke.php`、`tests/project_management_import_smoke.php` 和 `tests/project_monthly_smoke.php`。覆盖部门范围、全公司范围、撤权、停用、业务映射、主管实际代录和固定薪酬/全勤审批；不得连接生产数据库运行测试写入。
