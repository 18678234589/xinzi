# 客服绩效采集小工具（kefu_waiter）

给客服在自己电脑上用的桌面小工具。运行后托盘常驻，自动读取千牛/旺旺客户端会话，
统计 **进线会话数** 与 **客服首次回复秒数**，并把当月数据上传到财务系统，
用于「客服绩效底薪」结算。

> ⚠️ **重要风险提示**：旺旺没有开放接口，本工具通过 UI Automation 读取客户端窗口，
> 属于灰色操作，**存在被淘宝风控导致旺旺账号受限/封号的可能**。请先用 1–2 台电脑小范围试跑
> 3–5 个工作日，确认稳定且无风控现象后再全量推广。数据仅供参考，最终以财务系统管理页核对为准。

---

## 一、文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 启动入口（托盘、开机自启、上传） |
| `monitor.py` | 读取千牛/旺旺会话、记录进线与回复（v1，面向千牛PC标准版） |
| `recorder.py` | 本地数据保存（data/ 目录，JSON + 月度 CSV） |
| `uploader.py` | 上传月度 CSV 到服务器 |
| `config.ini` | 配置：服务器地址、token、员工姓名、旺旺账号 |
| `run.bat` | 源码方式运行（开发调试用，会弹窗口） |
| `build.bat` | 打包成单文件 exe |

## 二、第一次使用（给客服）

1. 安装 Python 3.8+ 后（只做一次）：
   ```
   pip install -r requirements.txt
   pip install pyinstaller
   ```
2. 用文本编辑器打开 `config.ini`，填写：
   - `url`：财务系统地址，如 `https://你的域名/kefu/upload.php`
   - `token`：与服务器 `config/cs_perf_config.php` 里的 CS_PERF_UPLOAD_TOKEN 一致
   - `name`：客服姓名；`wangwang`：客服旺旺账号（须在系统“员工管理”里先维护好对应旺旺账号）
3. 双击 `build.bat` 打包，得到 `dist\客服绩效采集工具.exe`。
4. 把 exe 发给客服，客服双击运行即可（可右键托盘图标开启“开机自启”）。

## 三、使用说明（客服）

- 运行后右下角出现绿色托盘图标，保持开机自启即可；电脑开着就自动记录、自动上传。
- 托盘菜单：
  - **立即上传数据**：手动把当月数据上传一次
  - **手动补记进线 +1**：自动没抓到但确实来过新客户时，手动补记一条
  - **开机自启**：勾选后开机自动运行
  - **退出**：退出前会自动上传一次数据
- 本机数据保存在 exe 同目录下 `data/`（JSON 明细 + `cs_perf_YYYY-MM.csv` 月度汇总），可随时查看。

## 四、数据口径

- **进线会话数**：当天首次出现的新会话（买家）数。
- **回复速度**：每会话「买家进线 → 客服第一次发出回复」的秒数，取当月平均。
- 月度汇总 CSV 列：`员工姓名,旺旺账号,日期,进线数,回复总秒数,回复次数`。
- 服务器导入时按 **旺旺账号 → 姓名** 顺序匹配员工，匹配不到的进“待匹配”清单，在系统
  “客服绩效”管理页批量补录归属。

## 五、已知限制（需要现场迭代）

- v1 面向 **千牛 PC 标准版** 适配；千牛/旺旺升级后读取规则可能失效，届时需更新本工具。
- 会话识别与回复探测依赖窗口标题/控件文本特征，个别电脑的客户端皮肤或窗口布局不同时
  可能漏抓。解决办法：先用托盘“手动补记进线”兜底，并把多抓/漏抓情况反馈给开发者迭代规则。
- 回复探测按“输入框有内容→清空”判定发送，若有客服用快捷键或宏发送且界面无此变化则不计。
- 本工具不修改客户端任何数据、不干预登录态，仅做只读读取。

## 六、服务器侧配套

- 上传接口：`kefu/upload.php`（token 鉴权，落盘并即时导入）。
- 也可把 CSV 手动放到服务器 `storage/cs_perf_uploads/` 目录，由计划任务
  `scripts\cs_perf_sync.php` 定时自动导入（装一次：`scripts\install_sync_task.bat`，管理员权限）。
