# 项目合作结算中心开发状态

本模块与旧订单、旧薪资模块并行运行。部署新环境前先备份数据库，再执行 `php migrations/apply_project.php`；该脚本只创建 `project_*` 表并为已有项目订单的实收、退款生成一次性期初记录，不修改旧 `orders` 或 `salaries` 表。

当前已实现：

- 订单入口支持 AI 网站定制、网站模板、小程序开发、小程序客服、设计、代写客服和期刊；“网站客服”只保留为历史账户映射，客服新单按售卖产品选网站模板或 AI 网站定制。业务专属字段保存于 `project_order_details` 并在结算单展示。
- 手动录入可展开/收起；店铺从现有店铺管理列表选择；成本中心从左侧导航进入。需域名/服务器的业务才显示资源成本区。
- 导入页按业务核对表头，原 AI 网站定制 Excel 继续可用；其他业务可下载各自 CSV 表头，填写后支持 CSV/XLSX 上传。真实的其他业务样表尚未提供，具体字段目前按通用业务字段设计，可取得样表后继续精确映射。
- 技术、客服独立登录，服务端只允许查看本人参与订单和本人项目分成；财务可按月份与合作人员查看。
- 技术、客服、财务均可按 AI 网站定制模板手动创建订单，或拖拽上传 XLSX/CSV 逐行预览；合作人员只能导入表格中写了本人参与的订单。技术/客服报备售价，财务确认实收、审核收退款与特殊成本。
- 技术、客服两组分别按项目贡献利润返佣，多人权重分摊并保存审核快照。
- 项目分成归属月份可选，财务可锁定月份；已锁月份不接收新的分成快照。
- 手动选择“无需域名”不生成域名成本；选择已配置标准域名或服务器模板，则按服务器端模板版本和价格自动生成成本快照。Excel“是”仅在域名后缀、1 年周期与唯一模板明确匹配时自动选择，否则预览要求人工选模板；不会猜测售价或采购价。SSL 真实成本报备需技术补凭证、财务审核，否则订单不能审核生成分成。项目分成 CSV 导出与操作审计已实现。

已确认：原有客服绩效与新增客服项目分成**叠加**；技术同一订单**只保留新的利润分成**。月度页面按“原系统已结算金额 − 已核实旧技术同单分成 + 新技术/客服项目分成”试算，不改写原有 `salaries` 记录。旧系统只保存月度汇总且算法可能为阶梯/多模块，无法安全自动拆出逐单金额，所以财务须逐单录入旧分成金额、来源月份及核对依据；确实未计入旧系统时录入 0 元并说明原因。核对未完成时隐藏完整应结算金额，并禁止锁月。此处“锁月”仍只锁项目分成，不代表完整项目报酬已发放。

待后续完成：正式项目报酬结算单与发放流程、退款/成本补录调整单、续费订单与提醒、已发项目报酬锁定及银行表导出。正式启用前须由财务配置合作人员账户、成本模板、技术和客服返佣规则，并用实际订单做业务验收。

开发环境可运行 `php tests/project_finance_smoke.php` 和 `php tests/project_intake_smoke.php` 验证财务结算、订单录入、标准成本与 Excel 预览/导入。测试使用事务，临时记录在结束时回滚。XLSX 解析支持未启用 ZipArchive 的 PHP 环境，上传仍限 5 MB/500 行。当前开发库成本模板为空，财务须先在配置页填写真实的 .com 1 年采购价；文档里的 ¥75 只是示例，不会自动预置为实际成本。

订单号草稿与店铺上传补全：技术可先只填订单号；客服录入 AI 网站定制订单时须指定已有登录账号的技术，双方在同一张订单结算单中查看。付款昵称、售价、交易状态、店铺可留空；店铺订单上传时按完整订单号匹配，仅补空字段，跨店铺同号不猜测，人工已填售价不会被覆盖。售价不等于财务确认的实收，不会因为上传而产生收款记录或项目分成。订单结算单单独显示店铺交易状态与项目交付状态。资源未确认时为待办状态，技术确认域名后带入标准成本，未确认不能审核分成。对应回归为 `php tests/project_order_source_smoke.php`。

网站业务同单提交：客服先建网站模板或 AI 定制订单时须指定有效技术账号；模板技术在原单补交付资料、域名与服务器成本。技术先建单时可在原单关联客服，客服只补买家资料的空字段。已关联人员的 Excel 同号上传会合并至原单，已确认成本不再生成第二次；未关联人员不可用订单号套取订单资料。网站模板分成按《网站核算.xlsx》采用售价 3% 店铺服务费、技术池 13%、客服池 8%；网站定制客服池 10%，技术沿用 AI 定制规则。表中固定服务费、排名及月度奖励留在原月度模块，避免重复计入。新规则由 `migrations/20260923_website_commission_rules.sql` 幂等写入，不覆盖财务已有的具体业务规则。

## 批量操作、售后调整、外包成本（2026-09-23）

- **财务批量操作**（项目订单列表勾选）：按售价确认实收（跳过已有实收、售价待补、店铺交易关闭）、标记交付完成、批量审核（逐单独立事务，未通过的订单列出原因）。
- **售后调整**（已审核订单结算单）：登记退款与成本增减（冲减填负数），按审核快照的比例重算，与“原快照 + 以往调整”的差额写入 `project_commission_adjustments`，默认计入下一个未锁定月份；全额退款同时收回每单补助；原快照不变。报酬中心合计、明细、CSV 均含调整。
- **按售价百分比的成本**：成本模板“计价”可选“% 售价”；预置“华梦定制外包 = 售价 × 80%”（华梦为下游外包，订单无需本公司技术，客服分成照常）。
- **人员**：导入时同名人员按“已开通账号且能做该业务”→“部门对应业务”自动区分；去掉“软件开发部 / 外包”前缀；部门“网站资料员”“标书小程序”映射到网站模板 / 小程序开发；账户区可按部门一键开通（登录名 = 姓名，随机初始密码只显示一次）。
- **小程序开发**不再要求技术确认域名 / 服务器（成本仍可在结算单添加）。
