# 项目合作结算中心开发状态

本模块与旧订单、旧薪资模块并行运行。部署新环境前先备份数据库，再执行 `php migrations/apply_project.php`；该脚本只创建 `project_*` 表并为已有项目订单的实收、退款生成一次性期初记录，不修改旧 `orders` 或 `salaries` 表。

当前已实现：

- 订单入口支持 AI 网站定制、网站模板、小程序开发、小程序客服、设计、代写客服和期刊；“网站客服”只保留为历史账户映射，客服新单按售卖产品选网站模板或 AI 网站定制。业务专属字段保存于 `project_order_details` 并在结算单展示。
- 手动录入可展开/收起；店铺从现有店铺管理列表选择；成本中心从左侧导航进入。需域名/服务器的业务才显示资源成本区。
- 导入页按业务核对表头，原 AI 网站定制 Excel 继续可用；其他业务可下载各自 CSV 表头，填写后支持 CSV/XLSX 上传。真实的其他业务样表尚未提供，具体字段目前按通用业务字段设计，可取得样表后继续精确映射。
- 技术、客服独立登录，服务端只允许查看本人参与订单和本人项目分成；财务可按月份与合作人员查看。
- 技术、客服、财务均可按 AI 网站定制模板手动创建订单，或拖拽上传 XLSX/CSV 逐行预览；合作人员只能导入表格中写了本人参与的订单。技术/客服报备售价，财务确认实收、审核收退款与特殊成本。
- 技术、客服两组分别按项目贡献利润返佣，多人权重分摊并保存审核快照。
- 项目分成归属月份可选，财务可锁定月份；已锁月份不接收新的分成快照。
- 手动选择“无需域名”不生成域名成本；选择已配置标准域名或服务器模板，则按服务器端模板版本和价格自动生成成本快照。Excel“是”仅在域名后缀、1 年周期与唯一模板明确匹配时自动选择，否则预览要求人工选模板；不会猜测售价或采购价。SSL 真实成本报备需技术补凭证、财务审核，否则订单不能审核生成分成。项目分成 CSV 导出与操作审计已实现。

已确认：原有客服绩效与新增客服项目分成**叠加**；技术同一订单**只保留新的利润分成**。月度页面按“原系统已结算金额 − 已核实旧技术同单分成 + 新技术/客服项目分成”试算，不改写原有 `salaries` 记录。旧系统只保存月度汇总且算法可能为阶梯/多模块，无法安全自动拆出逐单金额，所以财务须逐单录入旧分成金额、来源月份及核对依据；确实未计入旧系统时录入 0 元并说明原因。核对未完成时隐藏完整应结算金额，并禁止锁月。此处“锁月”仍只锁项目分成，不代表完整项目报酬已发放。

## 上传容错与 AI 托底（2026-09-24）

- 部门原表常见写法直接可用：日期 260901 / 20260901、日期列无表头（数据像日期即识别）、“业务”列写项目描述（存为业务说明）、店铺简称（如“美呀美”→ 美呀美旗舰店，对不上按原文保存并提示）。所属组人员栏为空时可由上传人接单；若明确写了别人，不会自动把本人加进去。
- 订单类型没写时不再拦截：按描述关键字、本人同布局历史确认分类、AI 建议、业务默认顺序预选；上传人可逐行改选，系统会记住本次确认的主分类。财务可在订单结算单一键改类；已审核订单保留原快照，只在未锁定月份记录分成差额，也可把正确类目设为参与人未来上传的默认。
- **AI 托底**（`includes/ProjectAiFallback.php`）：没有分表能按表头别名识别时，AI 识别表头；状态写法系统不认识时 AI 判断已完成 / 未完成；订单类型给出 AI 建议（仍由上传人确认）。AI 方案校验后写入 `project_ai_solutions`（系统设置 › AI 托底记录），同样的表头 / 写法下次直接套用、不再调用 AI；财务可停用或删除；AI 调用失败也会记录。日期因含义随月份变化，不做存档。
- XLSX、CSV 与旧版 XLS 均可拖入（原件上限 20 MB）；旧版 XLS 在浏览器本地转换为解析用 XLSX（上限 25 MB），服务器仍保留中文文件名的原件。生产 PHP 上传限制需至少 50 MB，以容纳原件与转换件同次提交。AI 方案真正用于已提交订单后，系统日志另记“已应用”次数与时间，区别于仅预览的建议。

## 项目退款与返现（2026-09-24）

- 侧栏“退款与返现”对项目账号开放。任何登录人员可上传线索；非本人订单不展示余额。勾选后先登记待审，不会立即改变项目报酬。
- 兼容退款部、网站返现表和标准 CSV；支持淘宝店铺、支付宝、微信、银行卡。可按原订单号或原支付流水唯一关联项目订单；原业务标签不一致、订单未建档或渠道不明时照样留档待财务核实，不自动扣款。
- 原支付流水与退款流水分开保存。退款流水按渠道防重；无退款流水号时按原单、日期、金额和渠道防重。历史驳回记录可修正后重新提交。财务可在待审列表更正订单、原支付流水、渠道和退款流水；AI 表头方案仍在实际提交后记“已应用”。
- 财务通过时核对已审核实收和重复流水；退款作为实收冲减而非直接成本（避免双扣）。未审核订单记已审核退款，已审核订单按原快照在未锁定月份生成客服与技术的分成差额。驳回及重复上传不扣款。
